# 🚀 Kafka for Beginners

¡Bienvenido! Este repositorio contiene notas, ejemplos prácticos y proyectos iniciales para aprender **Apache Kafka** desde cero.

---

## 📌 Contenido del Repositorio

- **Conceptos Clave:** Arquitectura, Topics, Particiones, Brokers y Zookeeper/KRaft.
- **Producers & Consumers:** Ejemplos de publicación y consumo de mensajes.
- **Kafka CLI:** Comandos esenciales para gestionar temas y grupos de consumo.
- **Prácticas:** Configuración de un entorno local de Kafka con Docker.
